# Portfolio QHSE — Cédric Comblé

## Publication sur GitHub Pages
1. Créer un dépôt public nommé `portfolio` sur GitHub.
2. Déposer `index.html`, `style.css` et le dossier `assets` à la racine.
3. Dans **Settings > Pages**, choisir **Deploy from a branch**, branche `main`, dossier `/ (root)`.
4. L'adresse prévue sera `https://bassistedric.github.io/portfolio/`.

Le QR code du CV devra pointer vers cette adresse uniquement après vérification de sa mise en ligne.
